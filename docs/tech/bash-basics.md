# 命令行基础

## 什么是命令行

命令行（Terminal / 终端）是一个用**文字指令**操控电脑的工具。图形界面（鼠标点）和命令行（键盘敲命令）能完成同样的事，但命令行更强大、可复制、适合批量操作，也是 Git 的天然工作方式。

学习命令行不需要"背命令"，记住几个最常用的，其他用到时再查即可。

## 在 Windows 上怎么打开

本机用 Windows，推荐两个终端：

| 终端 | 怎么打开 | 特点 |
| --- | --- | --- |
| **Git Bash** | 安装 Git 后，在任意文件夹右键 → "Git Bash Here" | 与教程里的命令语法一致，推荐使用 |
| **PowerShell** | 开始菜单搜索 "PowerShell"，或在文件夹地址栏输入 `powershell` | Windows 自带，语法略有差异 |

::: tip 建议
本 Wiki 的教程都基于 Git Bash 语法，Windows 上请优先用 Git Bash。
:::

## 路径基础

命令行的核心是"我现在在哪、我要去哪"。

- `pwd` — print working directory，显示当前所在目录
- `ls` — 列出当前目录的内容（PowerShell 用 `dir`）
- `cd 目录名` — 进入某个目录（change directory）
- `cd ..` — 返回上一级目录
- `cd ~` — 回到用户主目录
- `cd` — 不带参数直接回到主目录

特殊符号：

| 符号 | 含义 |
| --- | --- |
| `.` | 当前目录 |
| `..` | 上一级目录 |
| `~` | 用户主目录（如 `C:\Users\你的名字`） |
| `/` | 路径分隔符（Windows 的 Git Bash 里用 `/`） |

::: tip 省事技巧
输入命令时按 **Tab** 键自动补全文件名或路径；按 **↑** 键调出上一条命令。这两个习惯能省一半时间。
:::

## 常用命令速查

### 文件和文件夹

```bash
ls                 # 查看当前目录内容
ls -la             # 查看全部内容（含隐藏文件）及详细信息
cd 目录名           # 进入目录
cd ..              # 返回上一级
mkdir 名字          # 新建文件夹（make directory）
touch 文件名        # 新建空文件
cat 文件名          # 查看文件内容（在终端里打印出来）
cp 源 目标          # 复制文件
mv 源 目标          # 移动或重命名文件
rm 文件名           # 删除文件
rm -r 文件夹名       # 递归删除整个文件夹
```

::: danger 删除谨慎
`rm` 删除的文件**不会进回收站**，`rm -r` 更是会连文件夹一起删，执行前一定确认路径。不确定就先 `ls` 看清楚。
:::

### 运行其他程序

```bash
npm run docs:dev      # 在项目里运行 npm 脚本（本 wiki 的启动命令）
node --version        # 查看软件版本
git --version
```

## 常见问题

### 1. 提示"command not found"

输入的命令不存在或软件未安装。先确认拼写，再用 `--version` 检查软件是否装好。

### 2. 路径里有中文或空格怎么办

用双引号包住整个路径：`cd "我的文件夹/子文件夹"`。

### 3. 提示"Permission denied"

权限不足，通常需要管理员身份打开终端，或检查文件路径是否输入正确。

### 4. 不小心删错了

命令行删除**没有撤销**。所以删除前养成习惯：先 `ls` 确认，必要时用 `git status` 检查是否已被 Git 管理（被 Git 管理且已提交的文件可以恢复）。

## 把命令串起来：一个真实例子

在本地跑起本 Wiki：

```bash
cd 你的目录/SUsite      # 1. 进入项目
npm install             # 2. 安装依赖（首次）
npm run docs:dev        # 3. 启动本地开发服务器
```

浏览器打开终端提示的地址（默认 `http://localhost:5173/`），改文件后页面会自动刷新。按 `Ctrl + C` 可停止服务器。
