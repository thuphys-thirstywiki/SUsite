# 快乐夜

## 什么是快乐夜？
物理系快乐夜是物理系传统学生活动之一，通过举办小型的文艺晚会活动，丰富物理系学生的课余生活，活动于秋季学期开学前在理科楼下沉广场举办，届时除学生表演外，物理系学生会会提供餐食以及娱乐摊位，为刚入学的新生以及物理系同学们带来丰富的活动。

2026年快乐夜概况：

    举办方：物理系学生会
    活动规模：约100人
    活动时间（入场到清场结束）：2026年9月13日 16:00-21:00

## 活动内容有什么？
相较于学生节等大型活动，快乐夜的台上节目以简单的个人节目为主（如乐器表演，歌唱等），更加轻松自由，鼓励同学们积极勇敢地展示自己，同时加入小游戏与点歌环节促进台上与场内的互动。场内则设置各类摊位，为观众提供餐食和相应的娱乐，类似游园会的形式，内场草坪上会设置野餐垫用于坐席，让观众在欣赏节目的同时也能体验场内别具特色的活动。

### 物理系每年不得不品鉴的特色
- 手工制作甜食摊位
提供棉花糖机，巧克力喷泉等设备，同时提供糖果等食品，供同学们自由DIY甜食。
- 液氮冰淇淋摊位
由物理系科协提供，是每年快乐夜的传统摊位，利用低温液氮制作口感独特的冰淇淋，由于涉及低温，制作均由经训练的物理系科协成员佩戴防护手套操作，会指派同学维护秩序，科协在迎新等活动中也设置过多次该摊位，已有丰富的经验，是每年快乐夜最为火热的摊位。
