# 迎新

每学年面向新同学的系列服务与破冰活动。本页只提供活动全景，具体执行细节与可复用资源分别放在关联文档中。

## 活动目标

- 帮助新同学完成入学初期的信息获取与社群连接；
- 让参与部门在明确分工下完成接待、引导与反馈；
- 将当年的时间线与问题沉淀为下一届可复用的经验。

## 文档清单

| 文档类型 | 内容 |
| --- | --- |
| 活动介绍 | 本页：目标、范围和整体协作关系 |
| 开展指南 | 时间线、分工、现场检查项与应急处理 |
| 流程总结 | 复盘结论、数据与下一届建议 |
