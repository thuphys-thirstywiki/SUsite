# 迎新复盘

每届活动结束后，用本页记录实际数据、未解决问题与下一届可以直接沿用的决策。事实与建议分开写，避免经验在交接中失真。

## 复盘框架

1. 目标是否达成，依据是什么；
2. 时间线、协作与资源分别发生了什么；
3. 下届应保留、调整、停止什么；
4. 需要转存到素材库的文件或外链。
