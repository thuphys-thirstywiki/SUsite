# 迎新开展指南

## 关键时间线

| 阶段 | 负责人需要完成的事 |
| --- | --- |
| 活动前 4 周 | 明确规模、场地与跨部门分工 |
| 活动前 2 周 | 发布报名、确认志愿者与物资清单 |
| 活动前 3 天 | 走场、确认联系人和应急预案 |
| 活动当天 | 签到、现场调度、问题记录 |
| 活动后 1 周 | 回收反馈，完成复盘 |

## 交接要求

把当年实际采用的排班、联系人、预算和问题记录链接到素材库或复盘页。不要只保留在聊天记录中。
