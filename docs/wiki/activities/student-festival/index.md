# 学生节

学生节是需要长期筹备、多部门协同的大型活动。活动主文档记录稳定结构，年度方案、素材与现场流程应从这里分别链接。

## 应维护的内容

- 活动介绍：定位、受众、固定协作方；
- 开展指南：筹备节奏、舞台与现场协同、风险清单；
- 流程总结：当届数据、问题和下一届建议。
