基于 [VitePress](https://vitepress.dev/zh/) 的静态维基。所有词条都是 `docs/wiki/` 下的 Markdown 文件。

## 目录结构

- `docs/wiki/` 下每一个 Markdown 文件对应一个词条；
- 新增一个文件 = 新增一个词条；
- 提交到 GitHub 后自动构建部署。
