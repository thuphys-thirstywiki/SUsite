# Wiki

这里是学生会的静态知识库。它按文档本身的归属存放，方便维护者查找、更新和复用；不要求读者按目录逐页阅读。

## 三类内容

| 分类 | 用途 | 组织方式 |
| --- | --- | --- |
| [活动](/wiki/activities/) | 活动介绍、开展指南与流程总结 | 按活动名称归档 |
| [可复用素材](/wiki/artifacts/) | 问卷、外链、往届文件与模板 | 按素材类型归档 |
| [组织知识](/wiki/knowledge/) | 制度、协作方式与必要背景知识 | 按主题归档 |

::: info 如何使用
找工作资料时使用搜索或从人员文档进入。维护者新增文档时，先确定它属于哪一类，再在页面末尾补上关联与被引用关系。
:::
