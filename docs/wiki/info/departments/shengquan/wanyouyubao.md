# 生权：万有预报
## Wanyou skills
生权部的日常万有预报工作已经实现了`/wanyou-forecast` skill 自动化，可以通过爬虫和二次认证登录校内外网页，自动读取近一周内的新闻并按重要性排序，形成完整的万有预报推送。只需要根据仓库的README文档介绍，安装、运行`/wanyou-forecast`指令，就能获得万有预报的秀米草稿。
万有预报程序仓库：[Wanyou GitHub 仓库](https://github.com/2007qqc/Wanyou/tree/main)
