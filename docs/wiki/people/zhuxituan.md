# 学生会主席

主席的第一任务不是记住所有细节，而是让目标、责任与交接在组织里可见。把具体知识留在 Wiki，把每学期要作出的判断留在这里。

## 每学期的阅读与行动

1. 回看 [活动目录](/wiki/activities/) 与各活动复盘，确定本学期的重点与风险；
2. 与主席团明确活动 owner、部门边界和需要决策的节点；
3. 检查 [组织知识](/wiki/knowledge/) 与可复用资源是否仍然可用；
4. 在学期末把关键决策、未完成事项和接棒人写入交接记录。

## 何时下沉到 Wiki

涉及可复用的流程、稳定事实或资产时，应更新 Wiki。只有本届的优先级、角色分工和判断记录留在人员文档或交接材料中。
