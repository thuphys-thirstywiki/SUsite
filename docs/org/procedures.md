# 常用流程与模板

> 占位页：沉淀学生会日常运转中反复用到的流程与模板。

## 建议收录

- **经费报销流程** — 报销标准、票据要求、审批环节
- **场地申请流程** — 各类场地（教室、报告厅、礼堂）的申请方式
- **物资借用流程** — 学生会公共物资清单与借用手续
- **宣传物料制作流程** — 海报、推文的审批与发布
- **活动报备流程** — 活动前需完成的安全报备与审批

每条流程建议用以下格式：

```markdown
## 流程名称

### 适用场景
（什么时候会用到）

### 操作步骤
1. 第一步……
2. 第二步……

### 所需材料
- 材料一
- 材料二

### 负责人
（该流程由哪个部门/职务负责）
```

::: tip 模板文件
如已有 Word/Excel 模板，可放入 `docs/public/templates/` 目录并在词条中链接下载。
:::
