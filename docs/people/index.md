# 人员文档

这里不按知识类别组织，而是按读者的身份与当前工作组织。每一页都是一条阅读路径：告诉你先理解什么、接下来完成什么，并把需要的细节链接到 Wiki。

## 选择你的入口

| 角色 | 从这里开始 | 你会获得 |
| --- | --- | --- |
| 物理系非学生会同学 | [参与活动与反馈](/people/physics-students) | 能参加什么、如何联系学生会 |
| 学生会主席 | [主席工作引导](/people/president) | 年度节奏、授权与组织交接 |
| 主席团成员 | [统筹与分管工作](/people/executive-team) | 目标拆解、跨部门协调与风险管理 |
| 部长或干事 | [部门工作入口](/people/departments/publicity) | 本部门的任务路径与常用资料 |

::: tip 不是另一份 Wiki
人员文档不复制知识正文。需要更新事实、流程或素材时，请回到链接的 Wiki 页面修改源头。
:::
