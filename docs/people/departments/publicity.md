# 文宣部门

文宣负责将活动信息清晰、及时地传递给同学，也负责让活动中的视觉和传播经验可以复用。

## 开始一项活动时

1. 进入活动 Wiki，确认活动定位、受众和时间线；
2. 与活动负责人对齐报名、预热、现场与回顾四个传播节点；
3. 将主视觉、文案模板、数据复盘存入 [可复用素材](/wiki/artifacts/)；
4. 在活动复盘中记录传播结果和下一届建议。
