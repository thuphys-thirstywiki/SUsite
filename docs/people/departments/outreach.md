# 联络部门

联络部门负责维护校内外协作关系，并让合作资源在换届后仍能被找到和判断。

## 工作重点

- 在活动开始前确认外部合作方、承诺与沟通边界；
- 将可复用联系人、合作资料和链接保存到素材库；
- 在复盘中记录合作效果、风险与下一届的沟通建议。
