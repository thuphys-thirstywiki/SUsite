# 关于本站

这是一个基于 [VitePress](https://vitepress.dev/zh/) 搭建的静态维基站点，所有词条都以 **Markdown** 文件编写，存放在仓库的 `docs/` 目录下。

## 它是怎么工作的

```
docs/                    # 所有 wiki 内容都在这里
├─ index.md              # 首页
├─ guide/                # 使用指南（就是你现在看的部分）
├─ org/                  # 组织与制度
├─ activities/           # 活动百科
├─ study/                # 学习指南
├─ life/                 # 生活指南
└─ public/               # 图片、Logo、图标等静态资源
```

- 每一个 Markdown 文件对应一个词条页面；
- 目录结构决定内容组织，新增一个文件 = 新增一个词条；
- 提交到 GitHub 后自动构建部署，无需手动发布。
