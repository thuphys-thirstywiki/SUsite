# 活动筹备指南

> 占位页：沉淀办活动的通用流程与经验，作为各品牌活动词条的公共参考。

## 通用流程

### 一、策划阶段
1. 明确活动目标、规模、时间地点、预算
2. 撰写策划案，报负责人/老师审批
3. 完成场地、物资、经费的申请与审批

### 二、筹备阶段
1. 组建工作组，明确分工（宣传、物资、场务、外联等）
2. 制作宣传物料（海报、推文、报名渠道）
3. 彩排或流程预演，确认应急预案

### 三、执行阶段
1. 按时间线推进各环节，专人盯场
2. 记录现场问题与突发情况

### 四、收尾阶段
1. 清点归还物资、结算报销
2. 归档照片与数据
3. 写 [活动复盘](/activities/planning#复盘模板)

## 复盘模板

```markdown
## 活动复盘：{活动名称}

### 基本信息
- 时间 / 地点 / 参与人数
- 预算与实际支出

### 做得好的
- ...

### 待改进的
- ...

### 沉淀的经验
- （写入对应活动词条）
```

## 常见风险

::: warning 场地冲突
热门场地需提前 2–4 周申请，并准备备选方案。
:::

::: warning 预算超支
每笔支出保留票据，报销前核对预算与实际差额。
:::
